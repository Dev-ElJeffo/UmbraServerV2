✅ 2. Aceitar Solicitação de Troca (accept_trade_request.php)

request_id = ID da solicitação (ex: 26). from_player_id = player_id de quem ENVIOU. A API aceita um ou outro (request_id tem prioridade).

Obtido em "Carregar Pendentes" ou no retorno de "Enviar". É o PK da tabela trade_requests.

player_id de quem ENVIOU (ex: ElJeffo = 1). Usar se não tiver request_id.

Token da conta que recebeu a solicitação. Como o token é da conta (não do personagem), qualquer token da conta serve — mesmo que o personagem que recebeu seja outro da mesma conta.

📋 3. Obter Convites Pendentes (get_pending_invites.php)

Carrega pendentes de ambos os usuários (A e B) para comparar.

❌ 4. Cancelar Troca Ativa (cancel_trade.php)

Se aparecer "Um dos jogadores já está em uma troca", use para cancelar a sessão ativa e poder testar novamente.

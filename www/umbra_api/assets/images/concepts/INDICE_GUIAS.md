## 🎯 Casos de Uso

### Caso 1: "Nunca usei o sistema"
```
1. Leia README.md (3 min)
2. Siga QUICK_START.md (2 min)
3. Adicione sua primeira imagem!
4. Mantenha CHEAT_SHEET.md aberto para consulta
```

### Caso 2: "Preciso adicionar 20 imagens"
```
1. Revise QUICK_START.md
2. Abra CHEAT_SHEET.md em outra aba
3. Use gallery.example.json como referência
4. Trabalhe com checklist do CHEAT_SHEET
```

### Caso 3: "Algo deu errado"
```
1. Consulte CHEAT_SHEET.md → Troubleshooting
2. Se não resolver, veja GUIA_GALLERY_JSON.md → Solução de Problemas
3. Compare seu JSON com gallery.example.json
```

### Caso 4: "Vou treinar alguém"
```
1. Mostre README.md (contexto geral)
2. Faça uma demonstração com QUICK_START.md
3. Deixe CHEAT_SHEET.md disponível
4. Para dúvidas: GUIA_GALLERY_JSON.md
```

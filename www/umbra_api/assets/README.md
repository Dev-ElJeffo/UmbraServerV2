# UmbraEternum - Assets

Este diretório contém todos os assets visuais do projeto.

## Estrutura

```
assets/
├── images/          # Imagens e backgrounds
│   ├── hero-bg.jpg  # Background hero section (1920x1080+)
│   ├── logo.png     # Logo principal
│   └── ...
└── icons/           # Ícones SVG
    ├── sword.svg    # Ícone de espada
    ├── shield.svg   # Ícone de escudo
    └── ...
```

## Assets Necessários

### Imagens Principais

1. **hero-bg.jpg** - Background da hero section (1920x1080 ou maior)
   - Tema: Castelo sombrio, floresta nebulosa, ou paisagem dark fantasy
   - Tons: Escuros com destaques dourados/roxos

2. **logo.png** - Logo UmbraEternum
   - Formato: PNG com transparência
   - Estilo: Gótico com elementos dourados
   - Tamanhos: 512x512 (original), 256x256, 128x128

3. **class-icons/** - Ícones de classes de personagem
   - warrior.svg
   - mage.svg
   - rogue.svg
   - cleric.svg
   - ranger.svg
   - paladin.svg
   - warlock.svg
   - monk.svg

### Texturas

- **parchment.png** - Textura de pergaminho envelhecido
- **metal.png** - Textura de metal oxidado
- **stone.png** - Textura de pedra antiga
- **leather.png** - Textura de couro gasto

### Ornamentos

- **border-ornament.svg** - Ornamento decorativo para bordas
- **divider.svg** - Separador decorativo
- **corner-ornament.svg** - Ornamento de canto para frames

## Fontes de Assets Gratuitos

- **Unsplash** (unsplash.com) - Imagens de alta qualidade
- **Pexels** (pexels.com) - Fotos e vídeos gratuitos
- **Font Awesome** (fontawesome.com) - Ícones vetoriais
- **Game-icons.net** - Ícones específicos para jogos
- **Freepik** (freepik.com) - Vetores e imagens (com atribuição)

## Notas

- Todas as imagens devem ser otimizadas para web
- Formatos recomendados: JPEG (fotos), PNG (transparência), SVG (ícones)
- Manter backup dos assets originais em alta resolução

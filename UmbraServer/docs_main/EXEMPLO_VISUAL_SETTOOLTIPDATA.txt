╔════════════════════════════════════════════════════════════════════════════╗
║ DICAS IMPORTANTES                                                           ║
╚════════════════════════════════════════════════════════════════════════════╝

1. EXPANDIR STRUCTS:
   - Clique na setinha (▼) no canto do nó Break para ver todos os campos
   
2. CONEXÕES DE DADOS vs EXECUÇÃO:
   - Pins COLORIDOS = Dados (string, int, bool, struct, etc.)
   - Pins BRANCOS = Execução (ordem em que os nós são executados)
   
3. VARIÁVEIS DO DESIGNER:
   - Se não aparecem nas variáveis, marque "Is Variable" no Designer
   
4. FORMAT TEXT:
   - Use {0}, {1}, {2} como placeholders
   - Conecte os valores aos pins 0, 1, 2
   
5. DEBUGGING:
   - Adicione nós "Print String" para ver os valores:
     ItemName → Print String ("ItemName: {0}")

═══════════════════════════════════════════════════════════════════════════════
                    EXEMPLO 4: ProgressBar_Health (Percentual)
═══════════════════════════════════════════════════════════════════════════════

[Break Umbra Character Info]
        │
        ├─→ Current Health (Int)
        └─→ Max Health Total (Int)
                │
                └─→ [Divide] (Float)
                        ├─ A: Current Health (Break) [converter Int → Float]
                        └─ B: Max Health Total (Break) [converter Int → Float]
                                │
                                └─→ Return Value (Float) → 0.0 a 1.0
                                        │
                                        └─→ [Set Percent]
                                                ├─ Target: ProgressBar_Health
                                                └─ Percent: Return Value (Divide)


NOTA: Se precisar converter Int para Float:
  [Current Health] (Int)
    ↓
  [To Float] (ou [Make Literal Float])
    ↓
  [Divide] A

═══════════════════════════════════════════════════════════════════════════════
                    COMO OBTER CADA NÓ
═══════════════════════════════════════════════════════════════════════════════

1. Break Umbra Character Info:
   - Clique direito → "Break Umbra Character Info"
   - Conecte Character Info (input) → Character Info (Break)

2. Format Text:
   - Clique direito → "Format Text"
   - Digite o formato manualmente no campo "Format"
   - Conecte os valores nos campos correspondentes

3. Set Text:
   - Clique direito → "Set Text"
   - Target: Arraste a variável TextBlock do "My Blueprint"
   - Text: Conecte a string (Break ou Format Text Return Value)

4. Set Percent:
   - Clique direito → "Set Percent"
   - Target: Arraste a variável ProgressBar do "My Blueprint"
   - Percent: Conecte o valor Float (0.0 a 1.0)

5. Divide:
   - Clique direito → "Divide" (Float)
   - A: Valor atual
   - B: Valor máximo
   - Return Value: Resultado (0.0 a 1.0)

6. Make Literal Float:
   - Clique direito → "Make Literal Float"
   - Digite o valor (ex: 100.0)
   - Use para dividir percentuais

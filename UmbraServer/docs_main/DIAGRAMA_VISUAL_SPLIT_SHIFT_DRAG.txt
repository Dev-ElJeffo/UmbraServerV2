                              COMO OBTER CADA NÓ
═══════════════════════════════════════════════════════════════════════════════

1. ONDRAGDETECTED (Override):
   - No Event Graph do WBP_InventorySlot
   - Right Click → Digite "OnDragDetected"
   - Selecione "Add Event" → "OnDragDetected" (o evento real, não "Event")
   - OU: No Designer, selecione o widget raiz, Details → Events → On Drag Detected

2. GET PLAYER CONTROLLER:
   - Right Click → "Get Player Controller"

3. GET KEY OU GET INPUT KEY STATE:
   - Right Click → "Get Key" OU "Get Input Key State"
   - Se usar Get Key: Conecte Player Controller ao Target
   - Se usar Get Input Key State: Conecte Player Controller ao Target
   - No Details do nó, encontre "Key" e selecione "Left Shift"

4. IS KEY DOWN?:
   - Right Click → "Is Key Down?"
   - Conecte o Return Value do Get Key ao Key

5. GET SLOT DATA:
   - Right Click → "Get Slot Data"
   - Selecione a função do UmbraInventorySlotWidget
   - Conecte "self" ao Target

6. BREAK UMBRA INVENTORY SLOT:
   - Right Click → "Break Umbra Inventory Slot"
   - Conecte o Return Value do Get Slot Data ao input

7. CREATE WIDGET:
   - Right Click → "Create Widget"
   - No Details, encontre "Class" e selecione "WBP_SplitInput"

8. SETUP SPLIT INPUT:
   - Conecte o Return Value do Create Widget ao Target
   - Right Click → "Setup Split Input"
   - Selecione a função que você criou no WBP_SplitInput

9. ADD TO VIEWPORT:
   - Right Click → "Add to Viewport"
   - Conecte o Return Value do Create Widget ao Target

10. SET INPUT MODE UI ONLY:
    - Right Click → "Set Input Mode UI Only"
    - Conecte Player Controller ao Target
    - Conecte SplitInputWidget ao Widget to Focus

11. RETURN HANDLED / RETURN UNHANDLED:
    - Right Click → "Return Handled" OU "Return Unhandled"

12. CREATE ITEM DRAG DROP OPERATION:
    - Right Click → "Create Item Drag Drop Operation"
    - Selecione a função do UmbraInventorySlotWidget
    - Conecte "self" ao Target

13. ROUND TO INT:
    - Right Click → "Round to Int"
    - Selecione "Round to Int (Integer)"

14. FORMAT TEXT:
    - Right Click → "Format Text"

15. SET TEXT:
    - Selecione o TextBlock no Designer
    - Arraste para o Event Graph
    - Selecione "Set Text"

16. SET MIN VALUE / SET MAX VALUE / SET VALUE (Slider):
    - Selecione o Slider no Designer
    - Arraste para o Event Graph
    - Selecione "Set Min Value", "Set Max Value" ou "Set Value"

17. GET SOURCE SLOT WIDGET (Variável):
    - Right Click → "Get Source Slot Widget"
    - Selecione a variável que você criou

18. REQUEST SPLIT ITEM:
    - Right Click → "Request Split Item"
    - Selecione a função do UmbraInventorySlotWidget
    - Conecte o Source Slot ao Target

19. REMOVE FROM PARENT:
    - Right Click → "Remove from Parent"
    - Conecte "self" ao Target

20. MAKE LITERAL INT:
    - Right Click → "Make Literal Int"
    - Digite -1 no campo Value

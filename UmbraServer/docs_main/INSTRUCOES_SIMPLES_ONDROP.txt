DICAS IMPORTANTES
================================================================================

1. SEMPRE verifique se o nó já existe antes de criar um novo
2. Use os nomes dos nós existentes (K2Node_IfThenElse_6, etc.) para localizar onde adicionar
3. Os pinos BRANCOS são de execução (execute)
4. Os pinos AZUIS são de objetos/referências
5. Os pinos VERDES são booleanos
6. Os pinos LARANJAS são inteiros
7. Se um nó não aparecer ao digitar, verifique se a função existe no C++
8. Compile o projeto C++ antes de tentar usar funções do GameInstance

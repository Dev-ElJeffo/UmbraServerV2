VANTAGENS:
- Pins de entrada são DADOS (coloridos)
- Pode conectar strings/cores diretamente
- Função "Pure" (sem execução)
- Mais simples e eficiente


╔════════════════════════════════════════════════════════════════════════════╗
║                   COMO CRIAR O SELECT CORRETAMENTE                          ║
╚════════════════════════════════════════════════════════════════════════════╝

PASSO 1: Adicionar nó Select
─────────────────────────────
1. Clique com botão direito no Graph
2. Digite: "Select"
3. Escolha o nó roxo "Select"


PASSO 2: Configurar o tipo do Index
────────────────────────────────────
1. Selecione o nó Select
2. No painel Details (lado direito)
3. Procure: "Index Pin Type"
4. Mude de "Integer" para "EUmbraItemRarity"

ANTES:                           DEPOIS:

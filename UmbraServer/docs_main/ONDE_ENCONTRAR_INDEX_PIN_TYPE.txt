PROBLEMA: Não vejo "Index Pin Type" no Details
CAUSAS POSSÍVEIS:
  1. Nó errado selecionado (selecione o Select novamente)
  2. Painel Details não está visível (Window → Details)
  3. Seção "Select" ou "Node" está colapsada (clique na setinha ▼)
  4. Versão antiga do Unreal que não tem essa feature
  
SOLUÇÃO:
  → Use Switch + Variável Local (método alternativo)


PROBLEMA: "EUmbraItemRarity" não aparece na lista
CAUSAS POSSÍVEIS:
  1. Enum não está compilado no C++
  2. Projeto não foi recompilado após adicionar o enum
  
SOLUÇÃO:
  1. Feche o Unreal Editor
  2. Compile o C++ (F5 no Visual Studio)
  3. Abra o Unreal Editor novamente
  4. Tente novamente


PROBLEMA: Select muda mas não mostra os valores do enum
CAUSAS POSSÍVEIS:
  1. Configurou Index mas não configurou Option
  
SOLUÇÃO:
  1. Para GetRarityText: Option Pin Type = String
  2. Para GetRarityColor: Option Pin Type = Linear Color

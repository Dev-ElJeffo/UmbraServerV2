                    FLUXO DE EVENTOS - EVENT GRAPH
═══════════════════════════════════════════════════════════════════════════════

[Event Construct]
        │
        ├─→ [Get Game Instance]
        │        │
        │        └─→ [Cast to Umbra Game Instance]
        │                 │
        │                 ├─→ [Bind Event to OnCharacterInfoLoaded]
        │                 │        │
        │                 │        └─→ [OnCharacterInfoLoaded_Event] (criado)
        │                 │
        │                 ├─→ [Bind Event to OnCharacterInfoFailed]
        │                 │        │
        │                 │        └─→ [OnCharacterInfoFailed_Event] (criado)
        │                 │
        │                 └─→ [Load Character Info]


[OnCharacterInfoLoaded_Event]
        │
        └─→ [Update Character Info Display]
                 │
                 ├─→ [Break Umbra Character Info]
                 │
                 ├─→ [Set Text] → Text_CharacterName
                 ├─→ [Set Text] → Text_Level
                 ├─→ [Set Percent] → ProgressBar_EXP
                 ├─→ [Set Text] → Text_EXP
                 ├─→ [Set Text] → Text_Strength
                 ├─→ [Set Text] → Text_Agility
                 ├─→ ... (outros stats)
                 ├─→ [Set Text] → Text_Health
                 ├─→ [Set Percent] → ProgressBar_Health
                 ├─→ [Set Text] → Text_Mana
                 ├─→ [Set Percent] → ProgressBar_Mana
                 ├─→ [Set Text] → Text_Stamina
                 ├─→ [Set Percent] → ProgressBar_Stamina
                 ├─→ [Set Text] → Text_PhysicalAttack
                 ├─→ ... (outros stats de combate)
                 └─→ [Update Equipment Slots]


[Update Equipment Slots]
        │
        ├─→ [Break Umbra Character Info]
        │
        ├─→ [Get Equipped Items] → TMap<EUmbraEquipmentSlot, FUmbraInventorySlot>
        │
        └─→ [Switch on EUmbraEquipmentSlot]
                 │
                 ├─→ [Case: Head]
                 │        │
                 │        └─→ [Get] (TMap) → [Break Umbra Inventory Slot]
                 │                 │
                 │                 └─→ [Set Brush from Texture] → Image_Slot_Head
                 │
                 ├─→ [Case: Chest]
                 │        └─→ ... (similar)
                 │
                 ├─→ [Case: Hands]
                 │        └─→ ... (similar)
                 │
                 └─→ ... (outros slots)


[Button_Close OnClicked]
        │
        └─→ [Remove from Parent] (self)

                    MAPEAMENTO DE STATS
═══════════════════════════════════════════════════════════════════════════════

STATS BASE (7):
  - Strength (Força)
  - Dexterity (Destreza)
  - Intelligence (Inteligência)
  - Vitality (Vitalidade)
  - Agility (Agilidade)
  - Constitution (Constituição)
  - Luck (Sorte)

RECURSOS (3):
  - Health (Vida) → Current / Max Total
  - Mana (Mana) → Current / Max Total
  - Stamina (Estamina) → Current / Max

STATS DE COMBATE (10):
  - Physical Attack (Ataque Físico)
  - Magic Attack (Ataque Mágico)
  - Physical Defense (Defesa Física)
  - Magic Defense (Defesa Mágica)
  - Accuracy (Acerto)
  - Dodge (Esquiva)
  - Critical (Crítico)
  - Movement (Movimento)
  - Resistance (Resistência)
  - Double Attack Rate (Taxa de Ataque Duplo)

PROBLEMA:
---------
Você está tentando conectar "Handled" ao "Return Value" do "Return Node"
no OnDrop, mas não conecta.


SOLUÇÃO RÁPIDA:
---------------
✅ DEIXE O PIN "RETURN VALUE" VAZIO!

Não precisa conectar nada! O Unreal automaticamente retorna "Unhandled"
quando o Return Value está vazio, e funciona perfeitamente.

POR QUE FUNCIONA VAZIO?
------------------------

O Return Node precisa retornar um "Event Reply".

Se você DEIXAR VAZIO:
→ O Unreal automaticamente retorna "Unhandled"
→ Significa: "Não consumi o evento, outros listeners podem processar"
→ Funciona perfeitamente para nosso caso!

Se você conectar "Handled":
→ Significa: "Consumi o evento, não propague mais"
→ Também funciona, mas não é necessário aqui
→ Às vezes dá erro de conexão dependendo da versão do Unreal

═══════════════════════════════════════════════════════════════════════════════
                          COMO OBTER CADA NÓ
═══════════════════════════════════════════════════════════════════════════════

1. Source Slot (PARÂMETRO):
   - Vem do K2Node_FunctionEntry_0 (entrada da função)
   - Arraste o pin "Source Slot" para onde precisar

2. Item Quantity (PARÂMETRO):
   - Vem do K2Node_FunctionEntry_0 (entrada da função)
   - Arraste o pin "Item Quantity" para onde precisar

3. Set Source Slot Widget:
   - Right Click → "Set Source Slot Widget"
   - Selecione a variável de instância SourceSlotWidget

4. Set Current Quantity:
   - Right Click → "Set Current Quantity"
   - Selecione a variável de instância CurrentQuantity

5. Get Slot Data:
   - Right Click → "Get Slot Data"
   - Selecione a função do UmbraInventorySlotWidget

6. Break Umbra Inventory Slot:
   - Right Click → "Break Umbra Inventory Slot"

7. Break Umbra Item Template:
   - Right Click → "Break Umbra Item Template"

8. Set Text:
   - Selecione o TextBlock no Designer
   - Arraste para o Graph
   - Selecione "Set Text"

9. Format Text:
   - Right Click → "Format Text"

10. Set Min Value / Set Max Value / Set Value:
    - Selecione o Slider_Amount no Designer
    - Arraste para o Graph
    - Selecione "Set Min Value", "Set Max Value" ou "Set Value"

11. Subtract:
    - Right Click → "Subtract"

12. Convert Int to Double:
    - Right Click → "Convert Int to Double"

13. Set Split Amount:
    - Right Click → "Set Split Amount"
    - Selecione a variável de instância SplitAmount

14. Make Literal Int:
    - Right Click → "Make Literal Int"
    - Digite o valor (1 para Subtract B, 1 para Set Split Amount)
